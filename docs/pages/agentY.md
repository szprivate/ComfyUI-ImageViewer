# Working with agentY

[Home](../index.md)

With [agentY](https://github.com/szprivate/agentY) installed, the viewer and the agent share selection, files and feedback. Without it, none of the following appears.

- **Grouped by stage**: agentY's output lands in the History with one group per pipeline stage (*Characters*, *Places* …) and a label per thumbnail.
- **Tag as asset…** (thumbnail context menu): names an image so agentY can refer to it as `#name`.
- **agentY: approve**: while a run waits at a review step, select the images to keep, right-click and approve. The run continues with that selection.
- **Send to agentY** (Annotate tool): sends your marks as an image and as text with your next message; during a review they count as feedback.
- **Selection**: agentY sees the thumbnails you have selected or are comparing ("use the selected ones").
- **Show me**: when asked, agentY opens files, cuts or scenes in the viewer.
- **Auto edit**, Paint's agent workflows, **Motion** renders and **Dataset** reviews are handled by agentY; see the respective pages.

## Chat panel

**ComfyUI ▸ agentY** in the lower bar (or **↗** in the sidebar header) moves the agentY chat into the viewer as a dock panel; it is the same conversation. **↙** or **✕** moves it back.

Thumbnails, file browser rows and, with <kbd>Shift</kbd> held, the current frame can be dragged into the chat as attachments.
